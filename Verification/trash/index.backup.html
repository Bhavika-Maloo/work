Clear Retry Flows

When verification fails, users need a clear path forward — not a dead end

Design Decision
Retry options shown in priority order

Instead of a generic error state, users see prioritised retry methods based on their verification type — reducing abandonment at the most critical drop-off point

Outcome

Clear error messages with actionable next steps, significantly reducing support escalations for failed KYC attempts

Verification at withdrawal

Faster withdrawals by removing unnecessary friction

Design Decision
Show inline warning at document submission

Before the user completes KYC — not at withdrawal. Show exactly what mismatched and highlight the conflicting field side-by-side so the user understands what to fix without guessing
